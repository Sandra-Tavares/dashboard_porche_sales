# Dashboard Porsche — Análise de vendas

## Objetivo

Estudo de visualização de dados e criação de dashboards com apoio de prompts de IA.

## Recursos presentes no HTML

- Filtros por modelo, ano e forma de pagamento.
- Indicadores de volume e receita.
- Gráficos de modelos por cidade, distribuição por ano e volume por cidade.
- Área de insights e tabela de vendas filtradas.

## Tecnologias e arquivos

HTML, CSS, JavaScript e Chart.js. `index.html` e `index_porche.html` contêm o painel; `prompt_dashboard_porche.txt` registra os requisitos; `tabela_porche_sanitizada.xlsx` contém a planilha disponibilizada.

## Visualização

Abra `index.html` no navegador com acesso à internet para carregar Chart.js. A renderização, os cálculos e a origem dos dados não foram validados. Projeto de estudo, sem indicação de vínculo oficial com a Porsche.
